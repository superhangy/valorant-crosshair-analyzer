## Implication
The 66-frame "clean" dataset (11.35% avg pre-aim %) is not clean — 54/66 (82%)
samples are measuring either a teammate's position, a spectated player's aim, a UI
element, or demon1's own gun model. Only 12/66 (18%) are confirmed real engagements.
A real retrain needs, in priority order:
1. A spectate-state filter: check for "SPECTATORS" HUD text or the death combat-report
   overlay, drop the frame entirely (can't be recovered — wrong player's aim).
2. A UI-state filter: detect the Tab-scoreboard overlay (drop frame) — cheap regex on
   whether the "NAME / ULTIMATE / KDA / LOADOUT" table region is present.
3. Hard-negative retraining for teammate-as-target using the frames above, since
   filtering can't fully solve it (nameplate/color aren't always legible) — this is
   the tradeoff flagged below about reintroducing a team-color signal.
4. A second-streamer-overlay/replay-tag filter for the two REPLAY frames (low priority,
   rare in this VOD, but worth a generic check since other pro VODs in the pipeline
   likely have similar donor-cam overlays).
